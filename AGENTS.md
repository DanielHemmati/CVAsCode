# Agent Behavior

- Use simple technical English.
- Keep explanations concise and practical.
- Read `PLAN.md` before you make changes.
- Follow the phases in `PLAN.md` and work on one phase at a time.
- Prefer the smallest correct implementation.
- Explain important AWS and Terraform concepts without unnecessary jargon.
- Manage AWS infrastructure with Terraform unless `PLAN.md` states otherwise.
- Use the AWS MCP tools for AWS operations and official AWS documentation.
- Follow AWS Well-Architected Framework principles.
- Do not use em dashes in AWS resource names or descriptions. Use hyphens instead.
- Do not store or expose secrets, credentials, API keys, tokens, or passwords.

## Required Skills

- Use `simple-english` for documentation and explanations.
- Use `terraform-skill` when writing, reviewing, or debugging Terraform.
